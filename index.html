Telecom GIS Infrastructure

Bharath InfraNet — BSNL 5G OFC Rollout

The Challenge: Digitizing physical route surveys, trenching, fiber blowing, and cable splicing for BSNL's nationwide 5G infrastructure rollout without losing precision on GPS coordinates.

Architecture Solution: Designed a robust Laravel REST API backend coupled with an optimized PostgreSQL database with spatial coordinate indexes. Surveyors capture field data through synchronized mobile endpoints with offline fallbacks.

Engineering Highlights:

  • Automated RKM (Route Kilometer) calculations based on successive coordinate waypoints.
  • Fiber splicing junction diagram schema with parent/child tube attribution.
  • PostgreSQL spatial indexing reducing route search queries from 1.8s to 45ms.
